# Known Issues & Workarounds — v1.0.0

This document tracks known limitations, hardware-specific behaviors, and operational workarounds in AI Dubbing Studio PRO v1.0.0.

---

## 1. Code Signing & Windows SmartScreen Notice
- **Status:** BLOCKED (No EV/OV code signing certificate bundled in repository).
- **Behavior:** When running the Windows NSIS installer or portable executable on a clean machine, Windows Defender SmartScreen may display: *"Windows protected your PC — Microsoft Defender SmartScreen prevented an unrecognized app from starting"*.
- **Workaround:** Click **"More info"** (*ព័ត៌មានបន្ថែម*), then click **"Run anyway"** (*ដំណើរការទោះជាយ៉ាងណា*). This is standard behavior for open-source and newly released applications without an established reputation certificate.

---

## 2. Microsoft Edge-TTS Service Dependency
- **Status:** OPERATIONAL with external dependency.
- **Behavior:** Edge-TTS relies on Microsoft's online neural speech synthesis endpoint. If the user's internet connection drops or if Microsoft rate-limits rapid sequential requests, voice synthesis may return `No audio received`.
- **Workaround:**
  1. Verify active internet connectivity.
  2. The application automatically retries failed clips up to 3 times with exponential backoff.
  3. Individual failed rows can be regenerated by clicking the row status indicator.

---

## 3. Faster-Whisper on CPU vs NVIDIA CUDA GPU
- **Status:** BY DESIGN.
- **Behavior:** On machines without an NVIDIA GPU or without CUDA 12 / cuDNN installed, Faster-Whisper automatically falls back to CPU execution (`int8` quantization).
  - CPU transcription speed: ~1.5x–3x real-time (a 1-minute video takes ~20–40 seconds).
  - GPU transcription speed: ~10x–25x real-time.
- **Workaround:** For systems with NVIDIA GPUs, ensure the latest NVIDIA display drivers are installed. In **Settings > Speech Recognition**, set Device to `cuda` and Compute Type to `float16`. For low-power CPUs, choose the `tiny` or `base` model.

---

## 4. Real-Time Pitch Shifting Preview
- **Status:** PREVIEW LIMITATION (Applies during Final Export).
- **Behavior:** Changing the Voice Pitch slider adjusts the target pitch for the synthesized voice clip. Real-time audio pitch shifting is not rendered in the timeline preview to prevent audio buffer latency and distortion.
- **Notice:** Pitch transformations are applied with high fidelity during the final FFmpeg audio mix and video export.

---

## 5. First-Run Whisper Model Download
- **Status:** EXPECTED BEHAVIOR.
- **Behavior:** When transcribing with Faster-Whisper for the very first time on a given model size, the application downloads the model weights from Hugging Face:
  - `tiny`: ~75 MB (10–20 seconds)
  - `base`: ~145 MB (20–40 seconds)
  - `small`: ~490 MB (1–2 minutes)
- **Resume Capability:** If the download is interrupted, it automatically resumes from the last downloaded chunk via `resume_download=True`.
